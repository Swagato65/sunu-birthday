## 🚀 HOW TO RUN & VIEW LOCALLY

You can run this website right away using any simple static web server:

### Option A: Using Python (Installed on this computer)
```bash
python -m http.server 8000
```
Then open your browser at:
`http://localhost:8000`

### Option B: Using Node / npx
```bash
npx serve
```

### Option C: Direct Browser Opening
Simply double-click `index.html` to open it in Chrome, Edge, or Safari!

## 🌐 DEPLOYING TO GITHUB PAGES OR STATIC HOSTING

1. Push this folder to a GitHub repository.
2. In your GitHub repository:
   * Go to **Settings** > **Pages**
   * Under **Branch**, select `main` (or `master`) and folder `/ (root)`
   * Click **Save**
3. Your secret website will be live at `https://<your-username>.github.io/<repo-name>/`!
